SOP BƯỚC 1

1. Khảo Sát & Tiếp Nhận Yêu Cầu (Discovery & Requirement Analysis)

Plugin giúp cài đặt 1-click bộ combo các plugin chuẩn quen thuộc (Classic Editor, ACF, CF7, RankMath...) trực tiếp từ WordPress.org qua hàng đợi Client Queue mà không gây nghẽn RAM server.

💡 WOW Factor: Khởi tạo trang web mới siêu tốc, chọn combo sẵn (Stack Presets) và tự động tải phiên bản mới nhất từ WordPress.org API.
SOP BƯỚC 2

2. Phân Tích & Lập Kế Hoạch (Planning, CSDL & API)

Cấu hình Option Array `wdm_quick_installer_presets` lưu danh sách các plugin theo chủ đề (SEO, E-commerce, Performance, Security).

// AJAX Action Endpoints
wp_ajax_wdm_quick_install_plugin  - Tải & giải nén 1 plugin từ WP.org ZIP
wp_ajax_wdm_quick_activate_plugin - Kích hoạt plugin đã cài vào hệ thống
SOP BƯỚC 3

3. Thiết Kế Cấu Trúc (Information Architecture)

Sử dụng Lớp `Plugin_Upgrader` và API `plugins_api()` của WordPress Core để kết nối kho dữ liệu chính thức.

SOP BƯỚC 4

4. Thiết Kế Giao Diện (UI/UX & Admin Dashboard)

Giao diện danh sách bộ plugin với các nút Checkbox chọn nhanh, thanh ProgressBar tiến trình cài đặt và bảng log trạng thái trực quan.

🎨 Bộ Mẫu Giao Diện Tham Chiếu

🗂️ Pattern 1: Stack Presets Cards

Hiển thị các bộ combo plugin sẵn (Bộ chuẩn SEO, Bộ bán hàng WooCommerce, Bộ tối ưu tốc độ).

📊 Pattern 2: Client Progress Queue

Thanh phần trăm tiến trình tải & kích hoạt plugin chạy bất đồng bộ realtime.

SOP BƯỚC 5

5. Phát Triển Core Code (Development & Implementation)

Lớp `WDM_Quick_Installer_Admin` xử lý enqueue assets và render giao diện. AJAX handler nhận `slug`, gọi `plugins_api('plugin_information')` lấy link nén `.zip` mới nhất.
