# ⚡ Trình Cài Đặt Bộ Plugin Nhanh (WDM Quick Stack Installer)

Plugin giúp lập trình viên và quản trị viên thiết lập website WordPress mới trong 1 click chuột bằng cách tải, cài đặt và kích hoạt song song/tuần tự một bộ combo plugin đã được lưu trước.

---

## 🌟 Tính Năng Nổi Bật

- **Danh Sách Plugin Hay Dùng:** Chọn nhanh các plugin quốc dân (Classic Editor, Elementor, ACF, Rank Math...) bằng hộp tích chọn.
- **Bảng Plugin Đã Cài & Live Filter:** Ô lọc tức thì trạng thái plugin (Đã bật / Đã tắt / Chưa cài).
- **Tìm Kiếm WP.org Trực Tiếp:** Tìm kiếm plugin từ thư viện WordPress.org bằng AJAX API không cần chuyển trang.
- **Hàng Đợi Máy Khách (Client-side Queue):** Gửi từng request cài đặt liên tiếp bằng JS, chống nghẽn server và chống Timeout (30s Maximum Execution Time).
