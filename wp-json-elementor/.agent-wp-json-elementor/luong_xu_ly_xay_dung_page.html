1 BỘ THIẾT LẬP BAN ĐẦU (PRE-BUILD CONFIGURATION)

1. Số lượng Section

Đếm tổng số khối Section cấu thành trang (Loại bỏ Header & Footer).

2. Tên từng Section

Định danh theo chức năng: Banner, Categories Grid, Bestsellers, Mascot Mây, Partners, News.

3. Giao diện Tương ứng

Gom tài nguyên tham khảo: File HTML/CSS snippet, Ảnh screenshot mockup.

4. Hướng Xây dựng

Xác định nguồn dựng cho từng Section: Thư viện UI (Libraries) hay Dựng mới (Custom Scratch).
