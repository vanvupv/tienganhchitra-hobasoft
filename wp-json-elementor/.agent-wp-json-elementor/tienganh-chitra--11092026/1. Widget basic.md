# BỘ QUY CHUẨN JSON CỦA CÁC WIDGET CƠ BẢN (ELEMENTOR 3.x)

> **Nguồn trích xuất:** File `elementor-86-2026-09-11.json`  
> **Dự án:** Tiếng Anh Chị Trà  
> **Phiên bản Schema Elementor:** `version: "0.4"`, `type: "page"`  
> **Mục đích:** Chuẩn hóa cấu trúc JSON cho các Widget cơ bản nhất để tự động hóa sinh trang qua Python/JSON Builder.

---

## 1. CẤU TRÚC GỐC TOÀN TRANG (ROOT PAGE SCHEMA)

Một file JSON chuẩn của Elementor luôn có định dạng bọc ngoài cùng như sau:

```json
{
  "version": "0.4",
  "title": "Template Json",
  "type": "page",
  "page_settings": [],
  "content": [
    /* Danh sách các phần tử (Containers / Widgets) */
  ]
}
```

* **`content`**: Mảng chứa các Container cấp cao nhất (Root Containers).
* **`page_settings`**: Cài đặt trang (Canvas, Fullwidth, Page Title...).

---

## 2. CẤU TRÚC CONTAINER & GRID (LAYOUT WRAPPERS)

Trong Elementor hiện đại (Flexbox Container & Grid Engine), mọi widget đều bắt buộc nằm trong một **Container**.

### 🔹 2.1. Container Flexbox chuẩn
Khung chứa cơ bản để định hình bố cục (hàng ngang `row`, cột dọc `column`, căn lề `justify-content`, `align-items`).

* **JSON trích xuất từ file gốc:**
```json
{
  "id": "b5621d5",
  "elType": "container",
  "isInner": false,
  "settings": [],
  "elements": []
}
```

* **Cấu trúc mở rộng đầy đủ thuộc tính thường dùng:**
```json
{
  "id": "c_flex_01",
  "elType": "container",
  "isInner": false,
  "settings": {
    "content_width": "boxed",
    "width": { "unit": "px", "size": 1200 },
    "flex_direction": "row",
    "justify_content": "space-between",
    "align_items": "center",
    "padding": { "unit": "px", "top": "60", "right": "20", "bottom": "60", "left": "20" }
  },
  "elements": []
}
```

---

### 🔹 2.2. Container Grid (Lưới đa cột)
Khung chứa dạng CSS Grid hiện đại (chia 2 cột, 3 cột, 4 cột tự động đáp ứng).

* **JSON trích xuất từ file gốc:**
```json
{
  "id": "19199040",
  "elType": "container",
  "isInner": false,
  "settings": {
    "container_type": "grid",
    "presetTitle": "Grid",
    "presetIcon": "eicon-container-grid"
  },
  "elements": []
}
```

* **Cấu trúc mở rộng đầy đủ thuộc tính:**
```json
{
  "id": "c_grid_01",
  "elType": "container",
  "isInner": false,
  "settings": {
    "container_type": "grid",
    "presetTitle": "Grid",
    "presetIcon": "eicon-container-grid",
    "grid_columns_grid": { "unit": "fr", "size": 3 },
    "grid_rows_grid": { "unit": "fr", "size": 1 },
    "grid_gaps": { "unit": "px", "column": "24", "row": "24" }
  },
  "elements": []
}
```

## 3. BẢNG CHI TIẾT CÁC WIDGET CƠ BẢN ĐÃ XÁC ĐỊNH

| STT | Widget | `widgetType` | Mục đích sử dụng chính |
| :---: | :--- | :--- | :--- |
| **1** | **Heading** | `heading` | Tiêu đề chính, tiêu đề phụ (H1, H2, H3, H4) |
| **2** | **Image** | `image` | Hình ảnh minh họa, banner, ảnh đại diện, logo |
| **3** | **Text Editor** | `text-editor` | Đoạn văn bản, mô tả chi tiết, danh sách bullet |
| **4** | **Video** | `video` | Video giới thiệu (Youtube, Vimeo, Dailymotion, MP4) |
| **5** | **Button** | `button` | Nút kêu gọi hành động (CTA), liên kết tư vấn, đăng ký |
| **6** | **Icon** | `icon` | Biểu tượng trang trí, checklist tiện ích, tính năng |

## 5. QUY TẮC CẤU TRÚC CÂY (TREE HIERARCHY RULES)

1. **Quy tắc lồng cấp bắt buộc:**
   ```
   Root Page Schema
     └── Container (Root Section)
           ├── Container / Grid con (Ngang/Dọc)
           │     ├── Widget: Heading
           │     ├── Widget: Text Editor
           │     └── Widget: Button
           └── Container con (Cột đối diện)
                 └── Widget: Image / Video
   ```
2. **Quy tắc sinh ID:**
   - Mỗi phần tử (Container hoặc Widget) **bắt buộc phải có một `id` duy nhất** (chuỗi hex ngẫu nhiên 7-8 ký tự, ví dụ: `b5621d5`, `5ce0ea08`, hoặc dùng hàm `uuid.uuid4().hex[:8]`).
3. **Quy tắc `isInner`:**
   - Container gốc ngoài cùng: `"isInner": false`.
   - Widget và Container con bên trong: `"isInner": false` (hoặc `true` tùy phiên bản Elementor, nhưng trong template trích xuất 3.x mặc định đều là `false`).
