## 📐 2. CHI TIẾT KỸ THUẬT TỪNG SECTION

### SECTION 1: Banner Trang Tin Tức (Hero Page Header)
* **Cấu trúc Container:**
  * **Layout:** Full-width Container (`layout: full_width`).
  * **Min-height:** `400px` (Desktop) / `340px` (Mobile).
  * **Background:** Ảnh sự kiện trung tâm (`center center`, `size: cover`).
  * **Background Overlay:** Màu đen mờ `rgba(0, 0, 0, 0.48)` đảm bảo độ tương phản cao cho chữ trắng.
  * **Flexbox:** `flex-direction: column`, `justify-content: center`, `align-items: center`, `text-align: center`.
  * **Padding:** `top: 90px`, `bottom: 90px`, `left: 20px`, `right: 20px`.
* **Widgets bên trong:**
  1. **Tagline:** Heading Tag `span`, nội dung `NEWS & EVENTS`, font `Plus Jakarta Sans`, 13px, bold 700, uppercase, letter-spacing `2.5px`, màu `#FFFFFF`, line-height `1.2`.
  2. **Main Title:** Heading Tag `h1`, nội dung `TIN TỨC & SỰ KIỆN`, font `Plus Jakarta Sans`, 46px (Desktop) / 32px (Mobile), bold 800, line-height `1.2`, màu `#FFFFFF`.

---

### SECTION 2: Khối Bài Viết Nổi Bật Lấy Động 100% (Dynamic Featured Post)
* **Cấu trúc Container:**
  * **Layout:** Boxed `1200px`, `flex-direction: column`.
  * **Khoảng cách:** `padding: 50px 20px 20px 20px`.
* **Widget Sử Dụng:** **`posts`** (Skin `cards`)
  * **Cơ chế Query Động:**
    * `posts_post_type`: `"post"`
    * `cards_posts_per_page`: `1` (Tự động lấy bài viết mới nhất)
    * `cards_columns`: `1`
  * **Bố Cục Hiển Thị Ngang Chuẩn Mẫu:**
    * `cards_image_position`: `"left"` (Ảnh đại diện bài viết nằm bên trái ~45-50%, toàn bộ nội dung text nằm bên phải)
    * `cards_image_size`: `"large"`
  * **Chi Tiết Các Thành Phần:**
    1. **Badge Danh Mục:** Bật `cards_show_badge: yes`, taxonomy `category`, màu chữ trắng trên nền đỏ thương hiệu `#C8102E`, bo góc `4px`.
    2. **Tiêu Đề Bài Viết:** Heading `h3`, màu đen `#111827`, font 24px bold 800, line-height `1.2`. Tự động gắn link bài viết `the_permalink()`.
    3. **Meta Info:** Dòng tác giả và ngày đăng (`cards_meta_data: ["author", "date"]`), màu xám `#6B7280`, dấu phân tách `•`.
    4. **Trích Dẫn (Excerpt):** 32 từ tóm tắt bài viết, màu `#4B5563`, font 15px, line-height `1.6`.
    5. **Nút Đọc Tiếp:** Bật `cards_show_read_more: yes`, text `"Đọc tiếp »"`, màu cam thương hiệu `#ED9717`, font 14px bold 700.
  * **Khung Card & Viền Nổi Bật:**
    * Nền trắng `#FFFFFF`, viền `1px solid #E5E7EB`, bo góc `12px`.
    * Đổ bóng nhẹ sang trọng: `box-shadow: 0 6px 20px rgba(0, 0, 0, 0.05)`.
    * Padding nội dung trong: `24px 28px`.

---

### SECTION 3: Danh Sách Bài Viết (Posts Grid) & Phân Trang
* **Cấu trúc Container:**
  * **Layout:** Boxed `1200px`, `padding: 20px 20px 80px 20px`.
* **Widget Sử Dụng:** **`posts`** (Skin `classic`)
  * **Cơ chế Query:**
    * `posts_post_type`: `"post"`
    * `classic_posts_per_page`: `6` (2 hàng x 3 cột)
  * **Layout Cột:**
    * Desktop: `3` cột
    * Tablet: `2` cột
    * Mobile: `1` cột
  * **Tùy chỉnh Card Bài Viết:**
    * Bo góc: `10px`
    * Viền thẻ: `1px solid #E5E7EB`
    * Nền: Trắng `#FFFFFF`
    * Ảnh đại diện: `height: 200px`, `object-fit: cover`
    * Tiêu đề: Font 17px, bold 700, line-height `1.2`, màu đen `#111827`
    * Meta: Ngày đăng (`date`) + Tác giả (`author`)
    * Trích dẫn: 15 từ tóm tắt
    * Nút "Xem chi tiết →": Màu cam `#ED9717`
  * **Cài đặt Phân Trang (Pagination):**
    * `pagination_type`: `"numbers_and_prev_next"` (Đầy đủ nút `<` / `>` và số trang `1, 2, 3...`)
    * `pagination_page_limit`: `"5"`
    * `pagination_align`: `"left"` (hoặc `"center"` theo mẫu)
    * `pagination_spacing`: `12px`
    * Nút Active: Nền xanh dương `#007BFF`, viền xanh, chữ trắng.
