## 1. QUY TẮC CỐT LÕI (CORE RULES ĐÃ ÁP DỤNG)
1. **100% Khung Flexbox Container:** Toàn bộ cây giao diện sử dụng `elType: "container"` chuẩn Elementor 3.x, không dùng `section/column` lỗi thời.
2. **Padding Desktop Chuẩn:** Mọi Section nội dung đều có padding cố định:
   ```json
   "padding": { "unit": "px", "top": "30", "right": "40", "bottom": "30", "left": "40", "isLinked": false }
   ```
3. **Typography & Brand Tokens:**
   - Font chữ toàn trang: `Plus Jakarta Sans`.
   - Màu chủ đạo (Primary Teal): `#0D9488` $\rightarrow$ `#0F766E`.
   - Màu xanh dương khóa học: `#1B64B8` & `#0A4D92`.
   - Màu đỏ điểm nhấn Testimonial: `#B91C1C` & `#DC2626`.
   - Màu vàng kim nổi bật (Accent Gold): `#F59E0B` & `#FBBF24`.

## 2. CHI TIẾT CẤU TRÚC TỪNG SECTION

### 🌟 SECTION 1: BANNER FULL WIDTH
* **Mục đích:** Hiển thị Banner Hero trang chủ tràn viền 100vw toàn màn hình.
* **Layout:**
  - `content_width`: `"full"`.
  - `stretch_section`: `"section-stretched"`.
  - `padding`: `0px` (tràn viền không viền đệm).
* **Phần tử:** Widget `image` kích thước lớn full-width minh họa giáo viên và học sinh kèm slogan trung tâm.

### 👩‍🏫 SECTION 2: ĐỘI NGŨ GIẢNG VIÊN (Post Type: `giang_vien`)
* **Mục đích:** Giới thiệu đội ngũ giáo viên, chứng chỉ IELTS 8.0+, kinh nghiệm giảng dạy.
* **Layout & Style:**
  - Nền Gradient Xanh Ngọc / Teal bám sát mẫu thiết kế: `#0D9488` $\rightarrow$ `#0F766E` góc `135deg`.
  - Padding: `30px 40px`.
* **Phần tử chính:**
  - **Heading:** `"ĐỘI NGŨ GIẢNG VIÊN TẠI TIẾNG ANH CHỊ TRÀ"` (H2, 28px, chữ trắng `#FFFFFF`, font weight 800).
  - **Divider:** Họa tiết gạch nối màu vàng `#FBBF24` dài 90px.
  - **Text Editor:** Đoạn văn bản mô tả tâm huyết giáo dục.
  - **Grid 4 Card Giảng Viên:**
    - Mỗi card có bo góc 12px, nền kính mờ `rgba(255,255,255,0.08)`, viền trắng mờ.
    - Hiệu ứng Custom CSS: `selector:hover { transform: translateY(-6px); box-shadow: 0 12px 24px rgba(0,0,0,0.2); }`.
    - Gồm: Ảnh chân dung + Tên giảng viên + Bằng cấp & Chức danh màu vàng.

## 3. HƯỚNG DẪN IMPORT TEMPLATE VÀO WEBSITE

### Cách 1: Import qua trang quản trị WordPress (Dễ nhất)
1. Đăng nhập vào trang quản trị WordPress của website.
2. Vào menu: **Templates (Mẫu)** $\rightarrow$ **Saved Templates (Mẫu đã lưu)**.
3. Bấm nút **Import Templates (Tải mẫu lên)** ở góc trên.
4. Chọn file [`trang-chu-elementor.zip`](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20%282026%29/%2818%29%20TI%E1%BA%BENG%20ANH%20CH%E1%BB%8A%20TR%C3%80%20%2811092026%29/wp-json-elementor/.agent-wp-json-elementor/tienganh-chitra--11092026/trang-chu-elementor.zip) (hoặc file `.json`) $\rightarrow$ Bấm **Import Now**.
5. Mở trang chủ trong Elementor $\rightarrow$ Bấm nút biểu tượng Thư viện (Folder) $\rightarrow$ Tab **My Templates** $\rightarrow$ Chọn **Trang Chủ Tiếng Anh Chị Trà** $\rightarrow$ Bấm **Insert**.

### Cách 2: Tái tạo hoặc tùy chỉnh cấu trúc bằng Python
Khi bạn muốn thay đổi bất kỳ nội dung, số lượng card hay màu sắc, chỉ cần sửa dữ liệu trong script [`generate_trang_chu.py`](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20%282026%29/%2818%29%20TI%E1%BA%BENG%20ANH%20CH%E1%BB%8A%20TR%C3%80%20%2811092026%29/wp-json-elementor/.agent-wp-json-elementor/tienganh-chitra--11092026/generate_trang_chu.py) và chạy lệnh:
```bash
python wp-json-elementor/.agent-wp-json-elementor/tienganh-chitra--11092026/generate_trang_chu.py
```
Toàn bộ file JSON và file ZIP sẽ được đóng gói lại ngay lập tức!
