## 1. QUY TẮC CỐT LÕI (CORE RULES ĐÃ ÁP DỤNG)
1. **Khung Flexbox Container:** Tất cả các Section sử dụng `elType: "container"` chuẩn Elementor 3.x.
2. **Desktop Padding:** Chuẩn xác `padding: 30px 40px` (`top: 30px`, `right: 40px`, `bottom: 30px`, `left: 40px`).
3. **SỬ DỤNG WIDGET DỮ LIỆU ĐỘNG (POSTS / BLOGS / REVIEWS WIDGET):**
   - Không dùng khối card tĩnh thô sơ.
   - Toàn bộ danh sách bài viết / khóa học / giảng viên đều do **Widget `posts`** tự động query từ cơ sở dữ liệu WordPress.
   - Phần đánh giá do **Widget `reviews`** (Elementor Pro Reviews) đảm nhiệm.

## 3. CHI TIẾT TỪNG SECTION

### 🌟 SECTION 1: BANNER FULL WIDTH
* **Layout:** Container Full Width (`stretch_section: "section-stretched"`), `padding: 0px`.
* **Phần tử:** Widget `image` kích thước lớn full-width.

---

### 👩‍🏫 SECTION 2: ĐỘI NGŨ GIẢNG VIÊN (Post Type: `giang_vien`)
* **Layout:** Container Boxed 1200px, Nền Gradient Xanh Ngọc/Teal (`#0D9488` $\rightarrow$ `#0F766E`), Padding: `30px 40px`.
* **Tiêu đề & Divider:** Heading H2 chữ trắng + Divider vàng `#FBBF24` + Subtitle mô tả tâm huyết.
* **Widget:** **`widgetType: "posts"`**:
  - `posts_post_type`: `"giang_vien"`
  - `classic_columns`: `"4"`
  - `posts_posts_per_page`: `"4"`
  - `classic_show_title`: `"yes"`
  - `classic_show_excerpt`: `"yes"`
  - `custom_css`: Bo góc 12px, viền kính mờ `rgba(255,255,255,0.2)`, hiệu ứng hover nâng card.

## 4. CÁCH IMPORT
1. Vào trang quản trị WordPress $\rightarrow$ **Templates** $\rightarrow$ **Saved Templates** $\rightarrow$ **Import Templates**.
2. Chọn file [`trang-chu-elementor.zip`](file:///e:/1.%20D%E1%BB%B0%20%C3%81N%20TH%E1%BB%B0C%20T%E1%BA%BE%20%282026%29/%2818%29%20TI%E1%BA%BENG%20ANH%20CH%E1%BB%8A%20TR%C3%80%20%2811092026%29/wp-json-elementor/.agent-wp-json-elementor/tienganh-chitra--11092026/trang-chu-elementor.zip).
3. Sau khi Import, Elementor sẽ nhận diện chính xác các Widget `posts` và `reviews`, tự động query bài viết theo từng Post Type đã đăng ký trong `functions.php`.
