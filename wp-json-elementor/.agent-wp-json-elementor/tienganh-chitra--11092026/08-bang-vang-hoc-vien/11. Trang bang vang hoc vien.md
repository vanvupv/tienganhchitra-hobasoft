```
┌────────────────────────────────────────────────────────────────────────┐

│ SECTION 2: BREADCRUMB (Trang chủ > Bảng vàng học viên)                  │
├────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────┤
│ SECTION 5: LƯỚI 8 THẺ HỌC VIÊN TIÊU BIỂU + PHÂN TRANG                   │
├────────────────────────────────────────────────────────────────────────┤
│ SECTION 6: NHỮNG CON SỐ ẤN TƯỢNG (4 KHỐI THỐNG KÊ COUNTER / ICON BOX)   │

│ SECTION 7: CALL TO ACTION BANNER (CÙNG CON TỰ TIN CHINH PHỤC TIẾNG ANH) │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. TIÊU CHUẨN KỸ THUẬT & QUY CHUẨN DỰ ÁN

1. **100% Native Elementor Widgets:** Hoàn toàn không dùng bất kỳ widget HTML nào. Các widget được dùng gồm: `heading`, `text-editor`, `image`, `button`, `icon`, `icon-list`, `yoast-breadcrumbs`, `shortcode`.
2. **Typography & Màu Sắc:**
   - Font: `Plus Jakarta Sans`, Line-height tiêu đề `1.2`.
   - Màu sắc chủ đạo: Xanh thương hiệu `#007BFF`, Navy `#002D62`, Vàng kim `#F59E0B`, Xám `#64748B`.
3. **Responsive Hoàn Hảo:** Tối ưu hiển thị chuẩn mực trên Desktop (4 cột), Tablet (2 cột) và Mobile (1 cột dọc).
