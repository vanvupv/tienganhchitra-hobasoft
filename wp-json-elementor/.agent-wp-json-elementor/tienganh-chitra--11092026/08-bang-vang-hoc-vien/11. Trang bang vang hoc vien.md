## 1. TỔNG QUAN KIẾN TRÚC TAB & POST ĐỘNG

Trang **Bảng Vàng Học Viên** sử dụng kiến trúc chuẩn của Elementor Pro: **Widget `nested-tabs` (Tabs) kết hợp Widget `posts` (Lưới bài viết học viên động kèm phân trang)**:

```
┌────────────────────────────────────────────────────────────────────────┐
│ SECTION 1: HERO BANNER (ẢNH HỌC VIÊN CẦM CÚP + TIÊU ĐỀ H1 + DÒNG MÔ TẢ)  │
├────────────────────────────────────────────────────────────────────────┤
│ SECTION 2: BREADCRUMB (Trang chủ > Bảng vàng học viên)                  │
├────────────────────────────────────────────────────────────────────────┤
│ SECTION 3: TIÊU ĐỀ H2 & WIDGET NESTED-TABS CHỨNG CHỈ                   │
│   ├── Tab Navigation: [IC3]  [Cambridge]  [IELTS]  [Giải quốc tế]       │
│   └── Tab Content (Container):                                         │
│         ├── Header Card giới thiệu chứng chỉ (Icon, Mô tả, Logo)       │
│         └── Widget POSTS (4 cột PC / 2 cột TB / 1 cột MB + Phân trang) │
├────────────────────────────────────────────────────────────────────────┤
│ SECTION 4: NHỮNG CON SỐ ẤN TƯỢNG (4 KHỐI THỐNG KÊ COUNTER / ICON BOX)   │
├────────────────────────────────────────────────────────────────────────┤
│ SECTION 5: CALL TO ACTION BANNER (CÙNG CON TỰ TIN CHINH PHỤC TIẾNG ANH) │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. TIÊU CHUẨN KỸ THUẬT & QUY CHUẨN DỰ ÁN

1. **100% Native Elementor Widgets:** Hoàn toàn không dùng bất kỳ widget HTML nào.
   - Các widget sử dụng: `nested-tabs`, `posts`, `heading`, `text-editor`, `image`, `button`, `icon`, `yoast-breadcrumbs`, `shortcode`.
2. **Dữ liệu động:** Danh sách học viên được nạp động qua widget **`posts`** (lấy từ Custom Post Type `hoc_vien` đã đăng ký trong `functions.php`), có phân trang số native.
3. **Typography & Màu Sắc:**
   - Font: `Plus Jakarta Sans`, Line-height tiêu đề `1.2`.
   - Màu sắc chủ đạo: Xanh thương hiệu `#007BFF`, Navy `#002D62`, Vàng kim `#F59E0B`, Xám `#64748B`.
4. **Responsive:** Tự động điều chỉnh 4 cột trên Desktop -> 2 cột trên Tablet -> 1 cột trên Mobile.
