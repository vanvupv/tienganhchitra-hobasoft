## 📌 1. TỔNG QUAN CẤU TRÚC TRANG GIẢNG VIÊN

Trang Giảng Viên được cấu thành từ 3 phần chính logic và liền mạch:

```
┌─────────────────────────────────────────────────────────────────────────┐
│ SECTION 1: HERO BANNER (Full-width Container / Min-height 400px)        │
│ • Nền: Ảnh đội ngũ giáo viên + Lớp phủ tối (Overlay 0.48)               │
│ • Tagline: "OUR TEACHERS" (13px, Bold 700, Uppercase, White)            │
│ • Title: "ĐỘI NGŨ GIẢNG VIÊN TÂM HUYẾT" (46px, Bold 800, H: 1.2)       │
└─────────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────────┐
│ SECTION 2: TIÊU ĐỀ & ĐOẠN MÔ TẢ NGẮN (Boxed 960px / Căn giữa)           │
│ • Tagline: "CHUYÊN MÔN & TẬN TÂM" (Xanh lá #28A745, Bold 700)           │
│ • Main Title H2: "NGƯỜI THẦY TRUYỀN CẢM HỨNG VÀ ĐỒNG HÀNH CÙNG CON"     │
│ • Mô tả ngắn: Tiêu chuẩn sư phạm quốc tế (IELTS 8.0+, TESOL, CELTA)...  │
└─────────────────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────────┐
│ SECTION 3: POSTS DANH SÁCH GIẢNG VIÊN (Boxed 1200px)                    │
│ • Widget: "posts" kết nối Custom Post Type "giang_vien"                 │
│ • Lưới: 4 Cột (Desktop) | 2 Cột (Tablet) | 1 Cột (Mobile)               │
│ • Card: Viền xanh lá #28A745, Bo góc 10px, Ảnh Cover 240px              │
│ • Phân trang: Phân trang số trang (Pagination Numbers)                  │
└─────────────────────────────────────────────────────────────────────────┘
```

## 📐 2. CHI TIẾT KỸ THUẬT TỪNG SECTION

### SECTION 1: Banner Trang Giảng Viên (Hero Page Header)
* **Cấu trúc Container:**
  * **Layout:** Full-width Container (`layout: full_width`).
  * **Min-height:** `400px` (Desktop) / `340px` (Mobile).
  * **Background:** Ảnh tập thể giảng viên (`center center`, `size: cover`).
  * **Background Overlay:** Màu đen mờ `rgba(0, 0, 0, 0.48)` đảm bảo độ tương phản cao cho chữ trắng.
  * **Flexbox:** `flex-direction: column`, `justify-content: center`, `align-items: center`, `text-align: center`.
  * **Padding:** `top: 90px`, `bottom: 90px`, `left: 20px`, `right: 20px`.
* **Widgets bên trong:**
  1. **Tagline:** Heading HTML Tag `span`, nội dung `OUR TEACHERS`, font `Plus Jakarta Sans`, 13px, bold 700, uppercase, letter-spacing `2.5px`, màu `#FFFFFF`, line-height `1.2`.
  2. **Main Title:** Heading HTML Tag `h1`, nội dung `ĐỘI NGŨ GIẢNG VIÊN TÂM HUYẾT`, font `Plus Jakarta Sans`, 46px (Desktop) / 32px (Mobile), bold 800, line-height `1.2`, màu `#FFFFFF`.

---

### SECTION 2: Tiêu Đề & Đoạn Mô Tả Ngắn (Intro Section)
* **Cấu trúc Container:**
  * **Layout:** Boxed `960px` (Khổ chữ tối ưu trải nghiệm đọc).
  * **Flexbox:** `flex-direction: column`, `align-items: center`, `text-align: center`.
  * **Padding:** `top: 60px`, `bottom: 30px`, `left: 20px`, `right: 20px`.
* **Widgets bên trong:**
  1. **Tagline:** Heading Tag `span`, nội dung `CHUYÊN MÔN & TẬN TÂM`, màu xanh lá `#28A745`, font 14px, bold 700, uppercase, letter-spacing `1.5px`, line-height `1.2`, margin-bottom `10px`.
  2. **Tiêu đề chính (H2):** Heading Tag `h2`, nội dung `NGƯỜI THẦY TRUYỀN CẢM HỨNG VÀ ĐỒNG HÀNH CÙNG CON`, font 28px, bold 800, line-height `1.2`, màu đen `#111827`, margin-bottom `16px`.
  3. **Đoạn mô tả ngắn (Text Editor):** Đoạn văn bản giới thiệu ngắn gọn, súc tích:
     > *"Tại Tiếng Anh Chị Trà, mỗi thầy cô không chỉ là người truyền thụ tri thức mà còn là người bạn đồng hành tin cậy, thấu hiểu tâm lý lứa tuổi và khơi gợi niềm đam mê tiếng Anh tự nhiên trong mỗi học sinh. Đội ngũ giáo viên 100% đạt chuẩn sư phạm quốc tế (IELTS 8.0+, TESOL, CELTA) với phương pháp giảng dạy tương tác sinh động, luôn theo sát tiến độ từng em để phát huy tối đa tiềm năng ngôn ngữ."*
     * Typography: Font `Plus Jakarta Sans`, size 16px, line-height `1.7`, màu `#4B5563`.

---

### SECTION 3: Posts Về Giảng Viên (Teachers Grid)
* **Cấu trúc Container:**
  * **Layout:** Boxed `1200px`.
  * **Padding:** `top: 20px`, `bottom: 80px`, `left: 20px`, `right: 20px`.
* **Widget Sử Dụng:** **`posts`** (Skin: `classic`)
  * **Cơ chế Query Động:**
    * `posts_post_type`: `"giang_vien"`
    * `posts_per_page`: `8` (Hiển thị 8 giảng viên/trang)
    * `pagination_type`: `"numbers"` (Hỗ trợ chuyển trang số 1, 2, 3...)
  * **Layout Cột:**
    * Desktop: `4` cột đều nhau
    * Tablet: `2` cột
    * Mobile: `1` cột
  * **Tùy chỉnh Card Giảng Viên:**
    * Bo góc thẻ: `10px`
    * Viền thẻ: `1px solid #28A745` (Xanh lá sinh khí nhận diện)
    * Ảnh đại diện: `image_size: medium_large`, `height: 240px`, `object_fit: cover`
    * Tiêu đề (Tên giảng viên): Font 18px, bold 700, line-height `1.2`, màu `#111827`
    * Trích dẫn (Trình độ/Kinh nghiệm): Font 14px, line-height `1.5`, màu `#4B5563`
    * Nút Xem chi tiết: Màu cam `#ED9717`, văn bản `Xem hồ sơ →`
    * Tự động gắn link: `the_permalink()` dẫn tới trang chi tiết giảng viên.
