## 📐 2. CHI TIẾT KỸ THUẬT TỪNG SECTION

### SECTION 1: Banner Trang Thư Viện (Hero Page Header)
* **Cấu trúc Container:**
  * **Layout:** Full-width Container (`layout: full_width`).
  * **Min-height:** `400px` (Desktop) / `340px` (Mobile).
  * **Background:** Ảnh hoạt động lớp học/ngoại khóa sôi nổi (`center center`, `size: cover`).
  * **Background Overlay:** Màu đen mờ `rgba(0, 0, 0, 0.48)` đảm bảo độ tương phản cao cho chữ trắng.
  * **Flexbox:** `flex-direction: column`, `justify-content: center`, `align-items: center`, `text-align: center`.
  * **Padding:** `top: 90px`, `bottom: 90px`, `left: 20px`, `right: 20px`.
* **Widgets bên trong:**
  1. **Tagline:** Heading Tag `span`, nội dung `PHOTO GALLERY`, font `Plus Jakarta Sans`, 13px, bold 700, uppercase, letter-spacing `2.5px`, màu `#FFFFFF`, line-height `1.2`.
  2. **Main Title:** Heading Tag `h1`, nội dung `THƯ VIỆN HÌNH ẢNH`, font `Plus Jakarta Sans`, 46px (Desktop) / 32px (Mobile), bold 800, line-height `1.2`, màu `#FFFFFF`.

---

### SECTION 2: Khối Thư Viện Ảnh (Filterable Gallery Section)
* **Cấu trúc Container:**
  * **Layout:** Boxed `1200px`.
  * **Flexbox:** `flex-direction: column`, `align-items: center`.
  * **Padding:** `top: 60px`, `bottom: 80px`, `left: 20px`, `right: 20px`.
* **Widgets bên trong:**
  1. **Tiêu đề Section H2:**
     * Widget: `heading`
     * Tiêu đề: `THƯ VIỆN ẢNH`
     * Typography: Font `Plus Jakarta Sans`, size 32px, bold 800, line-height `1.2`, màu xanh dương `#007BFF`.
     * Margin bottom: `24px`.
  2. **Widget Gallery Multiple (Elementor Pro):**
     * Widget: `gallery`
     * Cài đặt `gallery_type: "multiple"`: Cho phép chia nhiều nhóm danh mục ảnh độc lập.
     * **Danh sách các nhóm ảnh (Galleries):**
       * Nhóm 1: `Lớp học` (Ảnh lớp học giao tiếp vui vẻ, học viên thuyết trình tiếng Anh...)
       * Nhóm 2: `Hoạt động ngoại khóa` (Dã ngoại học thuật, English Speaking Club...)
       * Nhóm 3: `Lễ tốt nghiệp` (Lễ tốt nghiệp khóa K45, vinh danh học viên xuất sắc...)
       * Nhóm 4: `Giao lưu quốc tế` (Giao lưu văn hóa, ẩm thực, giáo viên bản ngữ...)
     * **Cài đặt Filter Bar (Thanh nút lọc danh mục):**
       * `filter_bar`: `"yes"`
       * `filter_bar_all_title`: `"TẤT CẢ"`
       * Kiểu nút: Dạng viên thuốc tròn (`border-radius: 99px`), padding `8px 20px`.
       * Nút Active: Nền xanh dương `#007BFF`, chữ trắng `#FFFFFF`.
       * Nút Thường: Nền trong suốt viền mảnh xám `#E5E7EB` hoặc nền `#F3F4F6`, chữ xám đen `#374151`.
     * **Cài đặt Lưới & Bố cục:**
       * `gallery_layout`: `"masonry"` (Tự động lấp đầy khoảng trống so le theo chiều cao tự nhiên của ảnh).
       * Số cột: 4 Cột (Desktop) / 2 Cột (Tablet) / 1 Cột (Mobile).
       * Khoảng cách giữa các ảnh (`gap`): `20px`.
       * Bo góc ảnh: `16px`.
       * Đổ bóng nhẹ: `0 8px 20px rgba(0, 0, 0, 0.08)`.
     * **Cài đặt Dải chữ đè chân ảnh (Overlay & Caption):**
       * `overlay_title`: `"title"`
       * Hiển thị: Dải gradient đen mờ ở chân ảnh (`rgba(0, 0, 0, 0.65)`).
       * Màu chữ: Trắng `#FFFFFF`, font `Plus Jakarta Sans`, 15px bold 700.
     * **Phóng to ảnh (Lightbox):**
       * `open_lightbox`: `"yes"` (Click vào ảnh tự mở Lightbox xem ảnh gốc sắc nét).
  3. **Nút "XEM THÊM" ở chân thư viện:**
     * Widget: `button`
     * Văn bản: `XEM THÊM`
     * Nền: Xanh dương `#007BFF`, chữ trắng, bo góc `99px`, padding `12px 36px`, font 15px bold 700.
     * Margin top: `40px`.
